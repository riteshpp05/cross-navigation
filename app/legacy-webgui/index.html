🏛️ Architecture Behind On-Premise to On-Premise Navigation

Why this exists: In large enterprise S/4HANA systems, users frequently navigate from modern Fiori Elements apps into deep, classic ABAP transactions (like VA03, ME23N, or FB03) that have not yet been rewritten in UI5.

  • Launchpad Host: On-Premise SAP Fiori Frontend Server (FES) or S/4HANA Embedded FLP (/sap/bc/ui2/flp).
  • Target Mapping Type: Transaction (Code: VA03) mapped in transaction /UI2/FLPD_CUST.
  • Web Dispatcher Routing: No SAP Cloud Connector needed! The browser navigates directly via the same corporate Web Dispatcher domain to /sap/bc/gui/sap/its/webgui.
  • System Alias: LOCAL (Same client/system) or RFC destination (Hub deployment).
